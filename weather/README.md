# Skylore

Location-aware weather storytelling — a scroll narrative of the next 7–14 days, powered by [Open-Meteo](https://open-meteo.com/) (no API key).

```bash
cd weather
npm install
npm run dev
```

Open `http://127.0.0.1:5173`. Share location or search for a place; the page persists your last choice in `localStorage`.
